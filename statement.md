# Project Statement

## Title
Hand Gesture Counter Using Computer Vision

## Problem
Recognizing simple hand gestures is a useful introductory computer-vision task. A lightweight system can use hand landmarks to determine which fingers are raised and convert that information into an understandable gesture label.

## Objectives
1. Detect a human hand.
2. Extract hand landmarks.
3. Count raised fingers.
4. Classify the count from ZERO to FIVE.
5. Provide a command-line executable implementation.

## Scope
The project focuses on static single-hand gestures and is intended for educational demonstration of landmark-based computer vision.
